# Aldi & Cindy Wedding Invitation

Static wedding invitation ready for GitHub Pages.

## Files
- `index.html`
- `style.css`
- `app.js`
- `data.js`
- `assets/`

## Run locally
Open `index.html` in a browser.

## Deploy to GitHub Pages
1. Upload all files to a GitHub repository.
2. Go to **Settings** → **Pages**.
3. Choose the branch that contains `index.html`.
4. Save.
5. Your site will be live at the GitHub Pages URL.

## Notes
- Music is in `assets/music/theme.mp4` and is played after the invitation is opened.
- Guest name can be customized with `?to=Nama+Tamu`.
